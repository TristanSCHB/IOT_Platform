# 🌐 Architecture Réseau

Nous devions utiliser le matériel fourni par l’école :

- Un Raspberry Pi 3
- Un dispositif capteur basé sur STM32

Pour utiliser le Raspberry Pi comme passerelle, nous devions le configurer en SSH.

Cependant, l’adresse IP du Raspberry Pi avait déjà été configurée par notre enseignant. Pour ne pas risquer de casser le système existant, qui fonctionnait déjà, nous avons choisi de ne pas modifier le fichier de configuration réseau.

Nous avons donc dû connecter le Raspberry Pi et notre machine au réseau de l’école afin que le Pi obtienne automatiquement la bonne adresse IP.
